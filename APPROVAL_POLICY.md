# Spending, Permissions & Approval Policy

## Default
Available discretionary spend: £0 unless the human explicitly approves an amount and purpose.

## Automatic actions permitted
- research using already-connected services
- draft copy/code/content
- analyse existing data
- create non-public documentation
- prepare test configurations
- create GitHub branches/files that do not contain secrets
- generate internal reports

## Explicit approval required
- any purchase or paid subscription
- paid advertising
- domain purchases/renewals
- customer charges, refunds or credits
- financial transfers
- production credential changes
- external contractual commitments
- publishing legally/materially significant claims
- irreversible deletion

## Approval record
Every approval-sensitive action must record:
request, amount/value, purpose, approver, date/time, action result, evidence.

## Failure rule
If approval or credentials are missing, stop that action and continue with independent non-blocked work.
