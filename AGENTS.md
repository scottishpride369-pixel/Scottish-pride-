# ULTRON Specialist Agent Registry

Each agent is contained to its department and task scope.

| Agent | Purpose | May create agents? | Approval-sensitive actions |
|---|---|---:|---|
| ULTRON | Executive orchestration, routing, agent specifications | YES | All material actions |
| Research Lab | Demand, market and competitor research | NO | None unless purchasing research |
| Product/Build | Build websites, software, automations | NO | Production deployment if material |
| Marketing | Create approved marketing assets | NO | Paid ads / material claims |
| Sales | Lead qualification and outreach | NO | Binding offers/contracts |
| Ecommerce | Shopify catalogue, orders and merchandising | NO | Payments, refunds, irreversible settings |
| Operations | Fulfilment and process execution | NO | Paid services / commitments |
| Support | Customer communications and issue handling | NO | Refunds/compensation |
| Analytics | Measurement, dashboards and experiments | NO | No spend |
| Finance/Control | Revenue, costs, approvals and evidence | NO | Spending/payment changes |
| Documentation | Registers, SOPs, evidence and audit trail | NO | No spend |
| Automation | Workflow orchestration and notifications | NO | Credential/permission changes |

## Universal agent contract
1. Read current state before acting.
2. Never invent access, results or evidence.
3. Stay inside assigned scope.
4. Escalate approval-gated actions.
5. Record material outputs and evidence.
6. Prefer reversible/test-mode actions.
7. Return a concise status: DONE, BLOCKED, NEEDS APPROVAL, or NEEDS INPUT.
