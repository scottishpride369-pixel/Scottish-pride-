## Conversion flow
Traffic → landing page → lead capture → qualification → secure payment → customer → fulfilment → support → testimonial/referral → measurement.

## System integrations
GitHub = source control and business documentation.
Vercel = production hosting/deployment.
PostHog = analytics and funnel measurement.
Notion = operating/project/task layer.
Shopify = existing commerce properties, retained as connected assets rather than the only public website.
Registrar/DNS = domain control and transfer workflow.
Payment provider = checkout with TEST/LIVE isolation.

## Design direction
Premium, modern, fast and mobile-first. One clear action per section. No dead buttons. The component system should support hundreds or thousands of digital-asset listings without redesign.
